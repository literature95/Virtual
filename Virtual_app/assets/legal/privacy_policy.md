# Virtual 隐私政策

**最后更新日期：2026 年 9 月 20 日**

Virtual（「我们」）重视您的隐私。本政策说明我们在您使用应用时**可能收集哪些信息、为何收集、如何使用与保护**，以及您享有的权利。

---

## 一、设计原则：本地优先

1. **对话记录、角色卡、世界书、预设等默认保存在您的设备本地**（SharedPreferences 等），不会自动上传我们的服务器。
2. 您配置的大模型 API 密钥保存在本地设置中，用于**由您的客户端直接请求**模型服务商；我们不设计将完整聊天内容经我方服务器中转的默认路径（除非您使用可选且明确开启的托管能力）。
3. 可选的自托管后端（账号 / 社区 / 角色广场）仅在您主动使用相关功能时处理必要数据。

## 二、我们可能处理的信息

### 1. 注册与账号（若您使用社区/账号功能）

- 邮箱地址、昵称、密码哈希（后端 bcrypt，不存明文密码）
- 邮箱验证码（注册/重置密码）
- 登录会话标识（JWT，用于识别登录状态）

### 2. 社区与角色广场（若您主动发布）

- 您发布的标题、正文、分类、标签、位置（若您同意发动态定位）
- 上传的角色卡数据与立绘文件
- 点赞、评论、关注等互动记录
- 发布定位时：经纬度及逆地理解析得到的地址文案（用于展示「位置」）

### 3. 技术与诊断

- 应用版本、平台类型、语言等设备相关信息（用于更新提示与兼容）
- 请求后端时的网络错误日志（用于排障）
- 若启用崩溃收集：错误堆栈（具体以构建配置为准）

### 4. 设备权限

| 权限 | 用途 |
|---|---|
| 网络 | 访问模型 API、可选后端、地图逆地理 |
| 定位（可选） | 仅在您于发动态时点击「所在位置」并同意后获取 |
| 相册/相机（可选） | 选择头像、角色立绘、聊天图片 |
| 麦克风（可选） | 语音输入（若使用 ASR） |

## 三、我们如何使用信息

- 提供注册登录、社区、角色卡分享等功能；
- 维护服务安全与稳定性，防止滥用；
- 向您展示应用内更新提示；
- 在法律法规要求时配合有权机关。

**我们不会出售您的个人信息。**

## 四、第三方服务

| 类型 | 说明 |
|---|---|
| 大模型厂商 | 您配置的 OpenAI 兼容 / Anthropic / Gemini 等，受其隐私政策约束 |
| 高德地图 | 发动态定位时用于逆地理编码，受高德开放平台政策约束 |
| 邮件服务（可选） | 后端配置 SMTP 时用于发送验证码 |

## 五、存储与安全

1. 本地数据随应用卸载可能一并清除，请自行备份。
2. 自托管后端的数据安全取决于您部署环境的配置；请妥善保管数据库口令与 JWT 密钥。
3. 我们采取合理的技术措施保护账号相关数据，但无法保证绝对安全。

## 六、您的权利

- 在设置中管理后端地址、清除本地数据；
- 修改昵称、简介、头像、密码；
- 选择不使用定位、不发布社区内容；
- 注销或停止使用账号（联系客服邮箱）。

## 七、未成年人

未成年人须在监护人同意下使用；若我们知悉在未获同意情况下收集了未成年人信息，将尽快删除。

## 八、政策更新与联系

政策更新时会在应用内或官网公示。疑问请联系：设置 → 关于 → 联系客服。
